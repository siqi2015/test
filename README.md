# Agent 算法预研工作规范

用于 agent 相关研究中的问题探索、方案讨论、架构设计、算法实验、功能实现、测试排障和阶段总结。

当前为 **v0.1 草稿**，已完成文档检查，尚未在真实任务或具体工具中验证。

## 阅读顺序

1. [主规则](skills/agent-research-workflow/SKILL.md)：研究与协作的通用要求。
2. [按任务选择工作方式](skills/agent-research-workflow/references/workflows.md)：探索、设计、实验、实现、检查及阶段整理。
3. [数据与验证](skills/agent-research-workflow/references/data-and-evidence.md)：完整采集、随机结果、公平比较和结论依据。
4. [表达要求](skills/agent-research-workflow/references/writing.md)：直接易懂地讨论、逐项推进和总结。
5. [模型路由案例](skills/agent-research-workflow/examples/model-routing.md)：示范如何应用规范；案例条件不是通用限制。
6. [使用说明](skills/agent-research-workflow/README.md)：草稿状态与后续适配事项。

## 使用原则

- 主动寻找不同可行方向，不把当前模型、成本和环境当作研究边界。
- 研究数据完整采集优先，保留失败记录和结论变化的依据。
- 先讨论并确认方案，再实现和验证；确认范围内不逐步重复询问。
- 阶段结束整理现有文档，减少重复，保留原始研究材料。

计划支持多个工具。具体安装位置、加载和触发方式需按工具适配；仅上传本仓库不会自动启用 skill。
