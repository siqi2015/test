# Agent 算法预研工作规范 v0.1

## 已确认要求

- 研究数据完整采集优先，不为省时省略原始记录。
- 主动探索不同方向，当前模型、成本、环境和实现不是天然边界。
- 方案和总结明确、直接、易懂，术语和数字需要解释。
- 先讨论并确认方案，再实现和验证；确认后的范围不逐步重复询问。
- 需要支持多个工具，通用规则保持一致，安装方式按工具适配。
- 要点讨论使用编号列表，方便逐项对照推进；原因与机制仍讲完整。
- 阶段结束整理文档与工作区，减少重复，保留数据、历史依据和未解决问题。

路由案例的正确率优先、具体模型和任务属于该案例，不推广为所有项目的固定要求。

## 阅读和使用

先读 [SKILL.md](SKILL.md)，按任务读取方法文件，不强制全读或复制文档。项目具体目标、运行命令、数据约定和研究状态放在已有项目说明中。

本目录采用常见 SKILL.md 格式，含 name、description 和相对引用。加载位置、启用及触发方式取决于使用平台，保存文件不会自动影响未来全部会话。具体工具明确后，分别适配入口并保留同一份通用规则；尚未验证各工具兼容性，不宣称直接复制即可全部生效。
